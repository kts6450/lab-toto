# DNSLab PLAY

**게임 오락실:** https://kts6450.github.io/lab-toto/

**별도 스포츠 토토:** https://kts6450.github.io/lab-toto/sports/

한 사람이 조작하고 나머지 사람들이 같은 화면을 관전하는 랩실 미니게임 모음입니다. **15가지 게임 · 게임당 3개 맵 · 총 45개 맵**, 음식 추천과 식당 랜덤 뽑기를 제공합니다. 얼굴 핀볼·경마·무궁화·물풍선·와사비·프레스·사다리·원판·탄막·리듬에 용암·블랙홀·폭탄·컬링·주가 롤러코스터를 추가했습니다.

## 명단

사용자가 제공한 Notion의 선택된 ‘재학 멤버’ 보기에서 16명을 가져왔습니다. `docs/members.js`에는 **이름과 사진 경로만** 저장합니다. 사진은 `docs/portraits/`에 원본 이미지 파일로 포함합니다. 다른 노션 속성이나 로그인 데이터는 저장·배포하지 않습니다.

화면에서는 오늘의 참여자를 제외하거나 다시 참여시키는 것만 가능합니다. 이름 추가·수정·사진 교체 기능은 없습니다. 지난 담당자를 다음 판에서 제외할 수 있습니다.

## 게임과 조작

| --- | --- | --- |
| 얼굴 핀볼 대탈출 | 테이블 흔들기 | 충돌하며 굴러간 공 중 먼저 출구로 빠져나온 3명 |

| 용암 발판 서바이벌 | 다 같이 긴급 점프 | 무너지는 발판에서 목숨을 잃고 탈락한 3명 |
| 블랙홀 중력 전쟁 | 중력 반전으로 밀어내기 | 실제 중력에 의해 블랙홀 중심에 흡수된 3명 |

| 얼굴 빙판 컬링 | 빙판 돌풍 | 실제 퍽 충돌·반사 후 위험 홀에 빠져 탈락한 3명 |
| 주가 롤러코스터 | 급락을 잠시 억제하는 서킷브레이커 | 결승에서 청산된 참가자, 결승 22초 경과 시 남은 인원 중 가상 가격 하위 참가자 |

Space로 액션, P로 멈춤 / 계속. 자동 조작을 켜면 직접 누르지 않아도 끝까지 진행됩니다. 다른 탭으로 이동하면 자동 일시정지됩니다. 완료한 결과는 최근 30판까지 현재 브라우저에 저장합니다. 취소한 판은 기록하지 않습니다.

각 게임은 실제 충돌, 이동, 조작, 경로, 점수 상태에서 결과를 계산합니다. 미리 담당자를 정한 뒤 애니메이션으로만 공개하는 방식이 아닙니다. 조작과 게임 규칙이 결과에 영향을 줄 수 있으므로 모든 게임을 엄밀한 균등 추첨으로 설명하지 않습니다.

## 맵 · 진행 시간 · 음악

게임마다 3개 맵을 직접 고르거나 랜덤으로 선택할 수 있습니다. 맵은 색뿐 아니라 중력, 장애물 배치, 노면, 압력, 숨은 함정 수, 사다리 연결, 회전 마찰, 탄막 방향, BPM, 안전 발판, 블랙홀 위치, 폭발 반경, 빙판 출구, 차트 변동성을 바꿉니다. 맵 선택은 브라우저에 저장됩니다.

예선 시간은 **45 / 75 / 105초**, 기본 75초입니다. 표시된 시간은 예선이며, 이후 실제 결승이 이어집니다. 예선에서 걸린 참가자는 재투입되고 위험도가 쌓입니다. 생존 게임의 결승 목숨, 경마 속도, 압력 게임의 펌프 압력, 와사비·사다리 함정 수, 원판 칸 크기, 폭탄 퓨즈에 위험도가 반영됩니다. 결승에서 선정된 사람은 다시 뽑히지 않습니다. 시간 표시는 일시정지 시간을 제외합니다.

주가 롤러코스터는 개인별 가상 가격, 캔들, 거래량, 롤러코스터 카트, 급등·급락, 서킷브레이커를 표시합니다. 네온 증시·코인 급락장·상장폐지 폭풍 맵의 변동성이 다릅니다. 실제 시세나 거래를 이용하지 않는 관전 게임입니다.

`docs/audio/`의 현악·브라스·합창·북 스타일 BGM 두 곡은 자체 합성·작곡한 오리지널 음악입니다. 게임 시작 클릭으로 음악을 켜고, 결승에서 두 번째 곡으로 전환합니다. 음악 ON/OFF와 볼륨을 저장합니다. 효과음은 음악과 별도로 켤 수 있습니다. 일시정지 시 음악도 멈추고, 결과 화면이나 게임 종료 시 음악을 페이드아웃합니다.

## 저장되는 식당 랜덤 뽑기

**오늘 뭐 먹지? → 우리 식당 목록**에서 식당 이름을 추가하고 저장된 목록으로 랜덤 뽑기할 수 있습니다. 여러 이름을 줄바꿈·쉼표·세미콜론으로 한꺼번에 입력해도 됩니다. 입력 즉시 자동 저장하며, 중복 이름은 하나만 남깁니다. 각 식당의 × 버튼으로 삭제할 수 있습니다. 최대 100개, 이름당 80자입니다.

목록은 같은 브라우저·같은 사이트의 `localStorage`에 저장되어 **새로고침 및 재접속 후에도 복원**됩니다. 다른 기기·브라우저와 동기화되지는 않으며, 브라우저 사이트 데이터를 삭제하면 지워집니다. GitHub Pages와 오프라인 HTML의 저장 목록은 각각 별개입니다.

## 원본과 참고

[Binary World 게임 모음](https://game.binaryworld.kr/)에서 단체 관전에 맞는 게임 방식을 참고해 랩실 명단 연동 버전을 별도로 구현했습니다. 원본 웹페이지는 `X-Frame-Options: DENY`로 외부 iframe을 차단합니다. 원본 프로그램이나 이미지·오디오 자산을 복사하지 않았으며, 각 카드의 **원본** 링크로 실제 원본 게임을 열 수 있습니다. 외부 원본에는 랩실 명단이 자동 전달되지 않습니다.

[Binary World 음식 추천](https://food.binaryworld.kr/)도 연결합니다. 내부 음식 추천은 카테고리·점심·회식 랜덤 뽑기와 사용자 후보 뽑기를 제공합니다. 음식 후보는 자체 목록입니다.

## 소스와 배포

`docs/index.html`, `docs/arcade.css`, `docs/arcade.js`, `docs/members.js`가 메인이며, `catalog.js`, `expansion.js`, `expansion.css`, `music.js`가 새 게임·맵·예선/결승·식당 저장·음악을 제공합니다. 이전 스포츠 토토는 `docs/sports/`로 이동했습니다. GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다.

다운로드 폴더의 `랩실오락실.html`은 CSS·JS·16명 사진·BGM이 포함된 오프라인 실행본입니다. 외부 원본 게임과 스포츠 토토 링크를 열 때에는 인터넷이 필요합니다.
