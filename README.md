# LAB TOTO

랩실 당번 리그. 10가지 관전형 미니게임으로 회의 주최자, 청소 담당, 냉장고 담당을 정합니다. 토토 스타일의 배당표와 선택형 가상 포인트 예측이 있습니다.

**플레이:** https://kts6450.github.io/lab-toto/

## 사용하는 방법

1. 선수 등록에 이름을 줄바꿈 또는 쉼표로 구분해서 추가합니다. 3–30명 지원합니다.
2. 이름 왼쪽 얼굴 버튼으로 사진을 등록합니다. `이름.jpg` 또는 `이름.png` 파일 여러 장을 한꺼번에 추가할 수도 있습니다. 사진 없이도 플레이할 수 있습니다.
3. 회의·청소·냉장고 탭에서 담당자로 예상하는 사람을 고릅니다. 예측은 선택 사항이며 최대 세 개의 서로 다른 담당을 예측할 수 있습니다.
4. 종목과 경기 길이를 고른 뒤 시작합니다. Space로 응원, P로 멈춤/계속. 다른 탭으로 이동하면 자동으로 멈춥니다.
5. 경기 종료 후 담당자 세 명과 포인트 정산을 확인합니다. 지난 경기 담당자 제외 옵션도 있습니다.

## 가상 포인트

무료 가상 포인트만 사용합니다. 현금 가치, 결제, 출금, 외부 계정은 없습니다. 기본 1,000P이며 무료 포인트를 계속 추가할 수 있습니다. 예측을 하지 않아도 게임을 진행할 수 있습니다.

단일 예측 배당은 참가자 수 `n`배입니다. 서로 다른 담당 `k`명을 예측하는 조합 배당은 `n × (n-1) × … × (n-k+1)`배이며, 선택한 예측이 모두 맞아야 적중합니다. 예를 들어 15명 중 세 담당을 모두 맞히면 2,730배입니다. 지급 포인트는 원금을 포함한 `베팅 포인트 × 배당`입니다. 경기 취소 또는 경기 중 새로고침 시 해당 베팅 포인트를 반환합니다.

## 공정성 및 저장

담당자 선정은 시작 시 `crypto.getRandomValues`를 이용한 균등 셔플로 결정하며, 게임별 다른 연출로 공개합니다. 각 참가자의 담당 선정 확률은 동일하고 세 담당자는 서로 다릅니다. 사진, 입력 순서, 가상 포인트 예측, 응원 횟수는 선정에 영향을 주지 않습니다.

명단, 축소한 사진, 최근 30판 결과, 포인트는 브라우저 `localStorage`에 저장합니다. 참가자 정보나 사진을 서버 또는 GitHub 저장소로 전송하지 않습니다. 각 사람의 브라우저 기록은 서로 공유되지 않습니다. 큰 화면 한 대에서 같이 관전하는 방식입니다.

## 소스 및 배포

`docs/index.html`이 모든 CSS/JavaScript/Canvas/Web Audio를 포함하는 독립 HTML입니다. 외부 의존성이 없고 파일을 직접 열어도 작동합니다. GitHub Pages는 `main` 브랜치의 `/docs`를 게시합니다. 변경 후 `docs/index.html`을 커밋하고 푸시하면 자동 배포됩니다.

10종목: 폭탄 배송 사고, 외계인의 인사 발령, 바닥이 퇴근했다, 레이저 야근 탈출, 열면 안 되는 택배, 블랙홀 출근길, 논문 운석 주의보, 수상한 시약 파티, 원자로 마지막 3인, 의자 없는 랩실 디스코.
