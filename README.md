# LAB TOTO · 가상 스포츠 토토

**플레이:** https://kts6450.github.io/lab-toto/

축구·농구·야구 경기의 승무패 / 승패, 핸디캡, 언더오버를 예측하는 스포츠 토토 게임입니다. 이전 당번 뽑기 미니게임은 모두 교체했습니다. 경기와 팀은 가상의 데이터이며 실제 경기 정보를 사용하지 않습니다.

## 플레이

1. 혼자라면 기본 참가자 ‘나’로 바로 플레이합니다. 랩실에서는 **선수 관리**에서 명단을 추가하고 얼굴 사진을 붙입니다. 1–30명, 참가자별 기본 지갑 10,000P를 제공합니다. 이전 버전에 저장한 명단·사진은 처음 실행할 때 가져옵니다.
2. 상단에서 베팅할 참가자를 고릅니다. 경기의 배당 버튼을 눌러 예측을 담고 포인트를 정해 **베팅 등록**을 누릅니다. 한 경기에서 한 예측만 담을 수 있습니다. 서로 다른 경기 2–6개를 묶으면 배당을 곱하는 조합 티켓이 됩니다. 참가자는 여러 티켓을 등록할 수 있습니다.
3. 모두 등록했으면 주최자가 **6경기 동시 시작**을 누릅니다. 축구·농구·야구 경기는 동시에 진행합니다. 중계 하단의 경기 버튼으로 시청할 경기를 바꿀 수 있습니다.
4. 최종 점수로 모든 티켓을 판정합니다. 조합의 모든 예측이 맞으면 `베팅 포인트 × 조합 배당`을 원금 포함으로 지급합니다. 지급액은 정수 포인트로 내림합니다.
5. **다음 라운드**로 계속 플레이합니다. 경기 길이는 20/40/60초, 카운트다운은 별도입니다. P로 일시정지 / 재개, Space로 응원합니다. 응원은 결과에 영향을 주지 않습니다.

## 랩실에서 함께하기

각자 이름으로 베팅하고 이번 라운드의 순이익으로 순위를 정합니다. 베팅한 참가자가 3명 이상이면 하위 세 명에게 회의 주최자·청소 담당·냉장고 담당을 배정합니다. 담당 이름은 자유롭게 수정할 수 있습니다. 동점 순위는 무작위입니다. 무료 충전은 순이익에 포함되지 않습니다.

‘모두에게 랜덤 단폴 100P’는 아직 이번 라운드에 베팅하지 않은 참여자에게만 티켓을 하나씩 등록합니다. 한 화면에서 함께 플레이하는 방식이며 서로 다른 브라우저·기기에서 기록이 공유되지 않습니다.

## 경기와 정산

- 축구: 정규시간 승무패, 홈팀 핸디캡, 양 팀 합계 언더 / 오버.
- 농구·야구: 동점이면 연장으로 승부 확정, 승패 / 핸디캡 / 언더·오버.
- 핸디캡: 표시된 값을 홈팀 점수에 더해 비교합니다. 홈 -1.5라면 홈팀이 2점 이상 차이로 이겨야 적중합니다.
- 모든 핸디캡·합계 기준은 0.5 단위라 동률에 따른 무효 정산은 없습니다.
- 팀별 득점 기대값을 사용하는 포아송 모델로 결과를 생성합니다. 배당은 같은 모델의 점수 분포에서 시장별 확률을 계산해 책정합니다. 경기 중계는 득점 이벤트를 시간 순서대로 공개합니다.
- 경기 시작 전 티켓 취소, 경기 전체 취소, 미완료 경기 새로고침 시 미완료 티켓의 포인트를 반환합니다. 완료한 티켓은 중복 지급하지 않습니다.

## 포인트와 저장

포인트는 무료이며 현금 가치가 없습니다. 결제·출금 기능이나 외부 계정은 없습니다. 무료 10,000P를 계속 추가할 수 있습니다.

명단, 축소된 사진, 지갑, 최근 티켓과 결과는 브라우저 `localStorage`에 저장합니다. 입력한 명단이나 사진을 GitHub 또는 다른 서버에 전송하지 않습니다.

## 소스와 배포

`docs/index.html`, `docs/styles.css`, `docs/app.js`로 구성됩니다. 외부 런타임 의존성이 없습니다. GitHub Pages는 `main`의 `/docs`를 게시하며 소스 수정 후 푸시하면 자동 배포됩니다. 다운로드 폴더의 `랩실오락실.html`은 CSS/JS를 포함하는 별도 오프라인 실행본입니다.
