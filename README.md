# DNSLab PLAY

**사이트:** https://kts6450.github.io/lab-toto/

**관전 추첨:** https://kts6450.github.io/lab-toto/?mode=solo

**직접 대결:** https://kts6450.github.io/lab-toto/?mode=party

**별도 스포츠 토토:** https://kts6450.github.io/lab-toto/sports/

관전 추첨과 직접 대결은 서로 다른 게임 목록과 엔진을 사용합니다. **관전 15종 / 45개 맵**, **대결 전용 5종 / 15개 맵**입니다. 재학 멤버 16명의 이름·사진, 담당 항목 편집, 음식·식당 추천, 오리지널 BGM을 포함합니다.

## 관전 추첨

한 사람이 큰 화면에서 진행하고 나머지는 관전합니다. 방을 만들거나 각자 접속할 필요가 없습니다. 핀볼·경마·무궁화·물풍선·와사비·프레스·사다리·원판·탄막·리듬·용암·블랙홀·폭탄·컬링·주가 롤러코스터 중에서 고릅니다.

예선은 45 / 75 / 105초 중 선택하며, 이후 실제 결승이 이어집니다. 진행자는 Space 또는 액션 버튼, P 일시정지로 조작하고 자동 진행도 가능합니다. 결과는 실제 충돌·진행 순위·반응·경로·점수로 정하며, 담당자를 미리 고르고 결과 영상만 보여주지 않습니다. 게임 규칙과 진행자의 조작이 영향을 주므로 모든 게임을 균등 추첨으로 설명하지 않습니다.

## 직접 대결

기존 관전 게임에 방만 붙인 모드가 아니라 별도의 실시간 대결 게임 5종입니다.

| 게임 | 참가자가 하는 조작 | 순위 기준 |
| --- | --- | --- |
| 범퍼 아레나 | 조이스틱 이동, 대시, 상대 밀어내기 | 생존 시간·추락·공격 점수 |
| 레이저 닷지 | 이동·회피, 개인 방어막 | 생존 시간과 피격 점수 |
| 코인 쟁탈전 | 이동해서 코인 수집, 대시로 코인 스틸 | 보유 코인 |
| 영토 페인트전 | 이동하며 바닥 점령, 페인트 폭탄 | 실제 소유한 칸 수 |
| 체크포인트 랠리 | 직접 운전, 니트로, 순서대로 코스 통과 | 체크포인트·완주 기록 |

모든 참가자가 자기 캐릭터를 동시에 조작합니다. 자동 이동이나 자동 스킬이 없으며, 상대와의 충돌·컨베이어·위험 구역 같은 환경 효과는 실제 게임 규칙으로 작용합니다. 진행자의 화면에는 참가자 조작·자동 조작 버튼이 없고, Space도 참가자 조작을 실행하지 않습니다. 진행자는 게임·맵 선택, 시작, 일시정지를 맡습니다.

1. **직접 대결**에서 전용 게임과 맵을 고르고 **방 만들기**를 누릅니다.
2. 초대 링크 또는 8자리 방 코드를 공유합니다.
3. 각자 자기 이름·얼굴로 입장하고 **준비 완료**를 누릅니다.
4. 준비된 인원으로 게임을 시작합니다. 최소 2명, 최대 16명이며 담당 항목 수 이상의 인원이 필요합니다.
5. 휴대폰에서는 가상 조이스틱·개인 스킬, 내 주변 확대/전체 경기장 전환을 사용합니다. 컴퓨터 참가자는 WASD/방향키와 Space를 사용할 수도 있습니다.

제한시간은 45 / 75 / 105초입니다. 종료 시 실제 점수·기록 하위부터 작성한 담당 순서대로 배정합니다. 동점은 추첨으로 순서를 정합니다. 낙하·피격 시 점수를 잃고 잠시 후 재투입되는 게임도 있어 끝까지 참여합니다. 중도 입장자는 다음 판부터 참여하며, 같은 이름의 동시 중복 입장은 거절합니다. 진행자 화면을 새로고침하거나 닫으면 방도 종료됩니다.

WebRTC 데이터 채널과 vendored PeerJS 1.5.5를 사용합니다. [PeerJS Cloud](https://peerjs.com/server/cloud)는 연결 중개를 맡습니다. 게임 계산·담당 선정은 진행자 브라우저에서 수행하고 참가자는 자기 입력만 보냅니다. 참가자의 위치·점수·결과를 받아 덮어쓰지 않습니다. 일부 학교망·NAT·방화벽은 직접 연결을 막을 수 있고, 그런 환경은 별도 TURN 중계가 필요합니다. [공식 연결 안내](https://peerjs.com/client/faq)를 참고할 수 있습니다. MIT 라이선스는 docs/vendor/peerjs-LICENSE.txt에 포함합니다.

## 담당 항목은 자유롭게 편집

**이번 판에서 정할 담당**에서 1~16개 항목을 추가·삭제·이름 변경할 수 있습니다. 회의·청소·냉장고 세 항목은 초기 예시이며 고정값이 아닙니다. 항목당 서로 다른 한 사람을 선정하므로 참가자가 항목 수보다 적으면 시작할 수 없습니다. 설정은 같은 브라우저에 저장되며, 지난 결과도 각 판의 담당 항목과 함께 최근 30판까지 보관합니다.

## 맵마다 실제 지형과 화면이 다름

맵 선택 카드에 실제 경기장 미리보기를 표시합니다. 예를 들어 경마는 원형 트랙 / 굽은 늪지 / 지그재그 하늘다리, 사다리는 세로 슬라이드 / 가로 심해 회로 / 지그재그 폭포, 물풍선은 수영장 풍선 / 스팀 탱크 / 달 표면, 프레스는 실험실 압착기 / 양쪽 기어 / 냉각 챔버입니다. 회전초밥은 실제 타원형 레일을 따라 접시가 이동합니다. 주가 롤러코스터는 네온 증시 / 코인 산맥 / 청산 절벽 화면과 변동성을 사용합니다.

직접 대결은 원형 발판·미로 벽·섬과 좁은 교량·사각 경기장을 사용합니다. 보이는 벽과 이동 가능 영역이 실제 이동·충돌에 적용됩니다. 레이저는 사방 포격 / 회전 빔 / 경고 후 폭발하는 타일, 코인은 창고 / 연결된 섬 / 컨베이어와 열차, 페인트는 공원 / 원형 점령 / 연결 통로 맵입니다.

## 명단 · 음식 · 음악

사용자가 제공한 Notion의 선택된 재학 멤버 보기에서 16명을 가져왔습니다. docs/members.js에는 이름과 사진 경로만 포함하며 다른 노션 속성·로그인 데이터는 배포하지 않습니다. 사진은 docs/portraits/에 포함합니다. 이름을 추가·수정하는 기능은 없고, 해당 판에서 제외·복귀시킬 수 있습니다.

**오늘 뭐 먹지? → 우리 식당 목록**에서 식당을 추가·삭제·랜덤 뽑기할 수 있습니다. 줄바꿈·쉼표·세미콜론 일괄 입력을 지원하며 중복을 제거합니다. 최대 100개, 이름당 80자이고 입력 즉시 자동 저장합니다. 같은 브라우저·같은 사이트에서는 새로고침·재접속 후에도 남으며, 다른 기기로 동기화되지는 않습니다. 사이트 데이터를 삭제하면 지워집니다.

docs/audio/의 현악·브라스·합창·북 스타일 두 곡은 자체 합성·작곡한 오리지널 BGM입니다. 시작 클릭으로 재생하며 결승·마지막 스퍼트에서 음악이 바뀝니다. 볼륨·음악·효과음을 따로 설정하고 일시정지·종료 시 음악도 멈춥니다.

## 참고와 배포

관전 게임은 [Binary World 게임](https://game.binaryworld.kr/)의 단체 관전 방식을 참고해 별도로 구현했습니다. 원본 프로그램·이미지·음악 자산을 복사하지 않았으며 원본 링크를 제공합니다. [음식 추천 원본](https://food.binaryworld.kr/)도 별도 연결합니다.

GitHub Pages는 main의 /docs를 배포합니다. arcade.js·expansion.js는 관전 게임, multiplayer-catalog.js·multiplayer.js는 별도 대결 게임, terrains.js는 맵별 화면, modes.js·modes.css는 메뉴·편집·미리보기, rooms.js·rooms.css·vendor/는 연결·개인 컨트롤러입니다. 이전 스포츠 토토는 /sports/에 별도 유지합니다.

다운로드 폴더의 랩실오락실.html에는 스타일·코드·16명 사진·BGM이 포함됩니다. 오프라인으로 관전 게임을 실행할 수 있으며, 휴대폰 대결 방은 온라인 사이트에서 만들어야 합니다.

검증: 60개 경기장 모두에서 담당 4개 배정, 전체 20개 엔진의 담당 1개·16개 경계값, 브라우저 15개 실제 동시 연결, 개인 이동·정지·스킬, 진행자 조작 차단, 결과 공유·추가 담당명 표시, 모바일 화면, 저장되는 식당 목록과 오프라인 실행을 확인했습니다.
